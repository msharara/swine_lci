# swine_lci

A transparent, cradle-to-farm-gate life cycle inventory (LCI) framework for livestock, piloting swine in North Carolina and Iowa (reference year 2022). It ties one shipped market pig to its feed, energy, chemicals, labor, manure handling, land and transport, with every number sourced and quality-scored.

- `containers/` JSON Schemas (draft 2020-12) for the 16 data containers, plus a field guide in `containers/guides/`.
- Plan and rationale: https://claude.ai/code/artifact/a3cbbad0-78a7-4491-9b5e-f151e017bfa2

Scope: inventory only (no impact assessment), open data only, no allocation in v1.
